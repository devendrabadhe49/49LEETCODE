# CodeIQ 🧠

A full-stack coding platform inspired by LeetCode — built to practice Data Structures & Algorithms with real code execution.

🔗 **Live Demo:** [49-leetcode.vercel.app](https://49-leetcode.vercel.app)

---

## 🚀 Features

- 💻 Code Editor with real-time execution (Judge0 API)
- 🔐 User Authentication (Login / Signup)
- 🧩 Coding Challenges with multiple difficulty levels
- 🤖 AI Chat Assistant for hints and help
- 📊 Submission History tracking
- 🛡️ Admin Panel for problem management

---

## 🛠️ Tech Stack

**Frontend:**
- React.js (Vite)
- Tailwind CSS
- Redux Toolkit

**Backend:**
- Node.js
- Express.js
- MongoDB
- Judge0 API (code execution)
